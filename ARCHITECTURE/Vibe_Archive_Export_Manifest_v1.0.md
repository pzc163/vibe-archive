# Vibe Archive Export Manifest Standard v1.0

> **Schema ID**: `vibe-archive.manifest.v1.0`  
> **发布日期**: 2026-04-26  
> **状态**: Stable  
> **规范地址**: `https://vibe-archive.dev/schema/manifest/v1.0.json`  
> **目标**: 定义训练数据集的元数据标准，使其成为可追溯、可复现、可审计的**数据产品**

---

## 1. 设计原则

> 一份训练数据集不是"一堆 JSONL 文件"，而是一个**数据产品**。
>
> 数据产品必须有：身份标识、来源追溯、质量报告、处理流水、合规声明。

---

## 3. 字段定义

### 3.1 身份标识

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `manifest_version` | `string` | ✅ | 固定 `vibe-archive.manifest.v1.0` |
| `dataset_id` | `string` | ✅ | 数据集唯一 ID（ULID/UUID） |
| `dataset_name` | `string` | ❌ | 人类可读名称，建议包含 domain + 时间 |

### 3.2 来源追溯（Source）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `source.schema_version` | `string` | ✅ | 源数据标准版本，如 `vibe-archive.task.v0.4.1` |
| `source.profile` | `string` | ✅ | Export Profile ID，如 `dpo` |
| `source.profile_version` | `string` | ✅ | Profile 版本，如 `1.0.0` |
| `source.generator` | `string` | ✅ | 生成工具标识，如 `vibe-archive-cli@0.2.1` |
| `source.generated_at` | `string` | ✅ | ISO 8601 生成时间 |
| `source.repository` | `string` | ❌ | 代码仓库地址 |

### 3.3 内容描述（Content）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `content.record_count` | `integer` | ✅ | 样本数量 |
| `content.task_ids` | `string[]` | ❌ | 源 Task ID 列表（小数据集可全量，大数据集抽样） |
| `content.file_path` | `string` | ✅ | 数据文件相对路径 |
| `content.file_size_bytes` | `integer` | ✅ | 未压缩的文件大小 |
| `content.format` | `string` | ✅ | `jsonl`, `json`, `parquet` |
| `content.compression` | `string` | ❌ | `none`, `gzip`, `zstd` |
| `content.checksum` | `object` | ✅ | 完整性校验 |
| `content.checksum.algorithm` | `string` | ✅ | `sha256`, `md5`, `blake3` |
| `content.checksum.value` | `string` | ✅ | 校验和值 |

### 3.4 处理流水（Pipeline）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `pipeline.stages` | `string[]` | ✅ | 执行的 Pipeline 阶段列表 |
| `pipeline.filter_config` | `object` | ✅ | **关键：用于复现数据集** |
| `pipeline.filter_config.min_quality_score` | `number` | ❌ | 质量分门槛 |
| `pipeline.filter_config.required_decision` | `boolean` | ❌ | 是否要求有 decision |
| `pipeline.filter_config.allowed_domains` | `string[]` | ❌ | domain 白名单 |
| `pipeline.filter_config.training_ready_only` | `boolean` | ❌ | 是否只取 training_ready |
| `pipeline.filter_config.date_range` | `object` | ❌ | 时间范围过滤 |
| `pipeline.post_process_config` | `object` | ✅ | **关键：用于复现数据集** |
| `pipeline.post_process_config.dedup_enabled` | `boolean` | ❌ | 是否去重 |
| `pipeline.post_process_config.dedup_method` | `string` | ❌ | `content_hash`, `semantic_hash` |
| `pipeline.post_process_config.max_tokens_per_sample` | `integer` | ❌ | 最大 Token 数 |
| `pipeline.post_process_config.trim_strategy` | `string` | ❌ | `preserve_system_and_recent`, `truncate_tail` |

### 3.5 质量报告（Quality）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `quality.avg_quality_score` | `number` | ❌ | 平均质量分 |
| `quality.min_quality_score` | `number` | ❌ | 最低质量分 |
| `quality.max_quality_score` | `number` | ❌ | 最高质量分 |
| `quality.test_pass_rate` | `number` | ❌ | 测试通过率 |
| `quality.has_user_modification_rate` | `number` | ❌ | 用户修改率 |
| `quality.avg_message_count` | `number` | ❌ | 平均消息数 |
| `quality.avg_tool_calls` | `number` | ❌ | 平均工具调用数 |

### 3.6 来源追溯（Provenance）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `provenance.source_tasks_count` | `integer` | ❌ | 原始 Task 总数 |
| `provenance.rejected_tasks_count` | `integer` | ❌ | 被拒绝的 Task 数 |
| `provenance.rejected_reasons` | `object` | ❌ | 拒绝原因分布 |
| `provenance.source_tools` | `object` | ❌ | 各 AI 工具贡献数量 |

### 3.7 合规声明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `license` | `string` | ❌ | 数据许可证，如 `CC-BY-SA-4.0` |
| `attribution` | `string` | ❌ | 归属声明 |
| `retention_policy` | `string` | ❌ | `keep_forever`, `auto_purge_30d` |
| `data_classification` | `string` | ❌ | `public`, `internal`, `confidential` |

## 5. 核心价值

| 场景 | Manifest 的作用 |
|------|----------------|
| **数据溯源** | 知道这份训练数据从哪些 Task 来、经过了什么处理 |
| **质量报告** | avg/min/max quality_score、test pass rate，一目了然 |
| **复现保障** | `filter_config` + `post_process_config` 确保任何人可以复现相同数据集 |
| **合规审计** | `retention_policy` + `license` + `provenance.rejected_reasons` |
| **版本管理** | `profile_version` + `schema_version` 确保上下游兼容 |
| **数据交易** | 作为数据产品的"说明书"，支持交换和定价 |

## 6. 与 Vibe Archive 生态的关系

```
Vibe Archive Task (v0.4.1)
    ↓ Pipeline (filter + normalize + transform + post-process)
Export Profile (dpo@1.0.0)
    ↓ Export Stage
JSONL Data File + Export Manifest (v1.0)
    ↓ 下游训练框架
LLaMA-Factory / Unsloth / Axolotl / OpenRLHF
```
